# Computer Architecture

This repository contains **lab assignments for the Computer Architecture course**, implemented using **RISC Assembly language**.

The purpose of this repository is to store and organize lab exercises that help students understand how instructions are executed at the hardware level and how low-level programs interact with the processor.

## 📚 Project Description

This repository includes multiple **Computer Architecture lab exercises** designed to practice fundamental concepts of **RISC-based assembly programming**.

The labs focus on topics such as:

* Basic **RISC instruction set**
* Register operations
* Arithmetic and logical instructions
* Memory access using **load/store**
* Control flow instructions (branching, loops)
* Basic input/output operations

These exercises help students understand how programs interact directly with the processor and memory at a low level.
